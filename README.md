# 简历工坊（Resume Editor）

一个可直接在浏览器中使用的在线简历编辑器，支持多模板切换、实时 A4 预览、证件照上传、多段项目经历以及 Word/PDF 导出。

## 在线体验

[https://jianli-editor.lsy42706.chatgpt.site](https://jianli-editor.lsy42706.chatgpt.site)

首次进入时所有简历内容均为空白。填写的数据只保存在当前浏览器的本地存储中，不需要注册或登录。

## 主要功能

- 五种简历模板：经典简洁、技术专才、现代双栏、极简留白、学术履历
- 基本信息、教育经历、项目经历、专业技能和自我评价实时编辑
- 支持添加多段项目经历和多条项目成果
- 模块主题名称、技能分类名称和内容排版可自定义
- 根据内容量自动调整字号与行距，适配 A4 页面
- 上传、更换或移除证件照，并自动裁剪为 4:5
- 保守优化已填写的项目措辞，不补写空白内容、不改变原意
- 支持撤销、重做和模块顺序调整
- 导出完整 PDF 或可继续编辑的 Word 文档
- 自动保存在浏览器本地，无需后端数据库

## 技术栈

- React 19
- Vite 6
- html2canvas + jsPDF
- docx
- Tabler Icons

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

启动后按照终端显示的本地地址在浏览器中打开。

## 构建与测试

```bash
npm run build
npm run test:sites
npm run test:mini
node --test tests/copy-optimizer.test.mjs
```

生产构建输出位于 `dist/`。

## 编辑体验与备份

- 桌面端并排编辑和预览，手机端可切换「编辑内容 / 查看预览」；A4 画布按屏幕比例缩放。
- 内容完善度按姓名、岗位、联系方式、教育、项目和技能的实际填写情况计算，切换步骤不会增加完成度。
- 「更多选项」支持导出 / 导入 JSON 备份，恢复前确认，恢复后可撤销。兼容旧版无版本号备份。
- 保存失败或本地数据损坏时显示提示；读取失败不会自动覆盖旧存储。导入只接受内嵌 JPEG / PNG 照片，不请求外部图片。
- 「预览设置」可隐藏空白模块；Word 按当前模块顺序导出并省略空白模块。Word 使用适合再次编辑的独立版式。
- 教育经历与专业技能分类可自由增加、删除，旧版单条教育及固定技能数据会在读取时转换；预览、备份和 Word 导出同步支持多条内容。
- 模板现有经典简洁、技术专才、现代双栏、极简留白和学术履历五种版式。
- 内容超出一页时提示页数。PDF 保留全部内容并按 A4 分页，分页处可能切开长段落，投递前请检查导出文件。

开发验证：`npm run build` 后运行 `node --test tests/*.test.mjs`。数据校验、存储异常与完善度测试位于 `tests/resume-data.test.mjs`。

## 微信小程序

使用微信开发者工具导入仓库根目录 `Omlo/`。项目配置已将小程序源码目录设为 `miniprogram/`，云函数目录设为 `cloudfunctions/`。仓库中的 `touristappid` 仅用于查看项目结构；微信身份登录需要完成以下配置：

1. 在微信公众平台取得自己的小程序 AppID，在微信开发者工具中替换项目 AppID，并开通、关联微信云开发环境。
2. 将云开发环境 ID 填入 `miniprogram/config/cloud.js` 的 `envId`。此值是客户端环境标识，不能代替 AppID 或云函数部署。
3. 在该环境中新建 `resume_drafts` 集合，权限设置为「仅管理端可读写」。草稿只能经 `resumeAccount` 云函数读写；不要开放客户端直连读写权限。
4. 在微信开发者工具中对 `cloudfunctions/resumeAccount` 执行「上传并部署：云端安装依赖」。保持为小程序调用的事件函数，不添加 HTTP 触发器。
5. 使用两个不同的微信账号真机登录，验证各自草稿互不出现、离线修改恢复和冲突处理，然后再上传审核。

仓库不保存真实 AppID 或本机私有配置。未配置环境 ID 时，登录按钮会明确提示尚未连接云环境。

小程序提供微信身份登录，云函数按当前微信用户的 OpenID 隔离草稿。编辑时先保存到当前账号的设备缓存，再自动同步到云端；同步失败可重试，多设备同时修改时可选择云端版本或确认用本机版本覆盖。登录时若发现未同步的设备草稿，会先让用户选择版本，并保留可恢复的本机备份。基本信息、教育经历、项目经历和专业技能可分步编辑，教育与技能分类可增删；另有五种预览样式、简历文字复制，以及与网页版兼容的 JSON 备份。小程序暂不原生生成 PDF/Word；需要文件时可将备份导入网页版导出。网页版与小程序不会自动同步。

## 数据与隐私

- 网页版简历内容和证件照保存在浏览器 `localStorage` 中。小程序草稿保存在微信云开发数据库，并按微信用户身份隔离；当前设备也保存一份账号专属缓存，以便同步失败时恢复。
- PDF 与 Word 文件均在浏览器端生成。
- 网页版不会将简历数据发送到服务器。小程序登录并编辑后，会把草稿发送到你配置的微信云开发环境。
- 清除浏览器站点数据会删除网页版的本地简历。小程序清除本机缓存会删除尚未同步的修改，请先检查同步状态或复制 JSON 备份。
